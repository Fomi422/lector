# Lector de palabras

Читалка испанских текстов для восстановления лексики: перевод слова по тапу, разбор глагольных форм, карточки с интервальным повторением. Устанавливается на iPhone как приложение (PWA) и работает офлайн.

## Как пользоваться

1. Откройте приложение в Safari и добавьте на экран «Домой» («Поделиться» → «На экран „Домой“»).
2. Запустите его с иконки и нажмите «Открыть файл глав» — выберите свой файл `lector-capitulos.json`.
3. Файл глав хранится только на устройстве. Тексты книг в этот репозиторий не входят.

## Справка по временам

Файл `grammar.js` — справка по временам (когда употребляется, как образуется, неправильные формы, ловушки). Пятое поле в словаре связывает слово с разделами справки, примеры подбираются из загруженных глав.

## Формат файла глав

```json
{
  "format": "lector-1",
  "title": "Название книги",
  "entries": [
    { "id": "abeja", "title": "abeja", "gist": "Кратко по-русски",
      "paras": [ [ ["Предложение по-испански.", "Перевод."] ] ] }
  ],
  "dict": { "слово": ["лемма", "часть речи", "перевод", "почему эта форма (необязательно)", ["imperfecto", "se"]] }
}
```
